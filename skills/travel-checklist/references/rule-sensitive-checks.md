# Rule-Sensitive Travel Checks

Read this reference when the user asks whether an item, document, medicine, battery, or bag is allowed, or when the checklist needs an airline-, border-, cruise-, venue-, or attraction-specific instruction.

## Source Order

1. Verify the operating carrier, venue, or destination authority's current official page.
2. Use the relevant airport, border, health, or park authority when it controls the requirement.
3. Use news, social posts, and community discussions only to identify a change worth checking; never treat them as the rule.

If no official live source is available, state that the rule is unverified, name the authority the traveler should check, and provide only non-rule packing precautions.

## Flight Batteries and Smart Luggage

- Do not quote fixed capacity, quantity, storage, or in-flight-use rules from memory.
- Verify the operating carrier's current rules, including any stricter route- or cabin-specific instruction.
- Keep power banks and spare batteries in an easy-access carry-on item. If a carry-on is gate-checked, remove them first when the carrier requires it.
- For smart luggage, check whether its battery can be removed before checking the bag.

## Medicine, Documents, and Attraction Items

- Do not decide import, prescription, visa, child-consent, customs, or venue-bag rules without a current official source.
- Keep the checklist practical while the rule is unverified: original packaging, copies of prescriptions or documents when relevant, offline booking records, and the official contact or page to check.
